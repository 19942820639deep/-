# A股尾盘免费行情快照

这个仓库只负责采集和校验公共A股行情，不产生买卖结论，也不存储任何账户、持仓或交易记录。

## 数据流程

1. 交易日北京时间14:30、14:35、14:40、14:45运行GitHub Actions。
2. 东方财富公共行情端点提供全A、指数、行业、概念和60分钟K线。
3. 腾讯公共行情端点交叉核验流动性候选股价格与成交时间。
4. 程序重新计算市场宽度、成交额、非ST涨跌停和炸板数量。
5. 只有时效、覆盖率、板块覆盖及跨源价格全部通过，`valid_for_tail_selection`才为`true`。

公开快照地址：

`https://raw.githubusercontent.com/19942820639deep/-/main/data/latest.json`

## 硬校验

- 指数服务器时间距采集时间不超过180秒；
- 全市场覆盖不少于4500只，且不低于上一份快照股票数的95%；
- 行业板块不少于30个，至少成功读取6个强势行业的成分股；
- 腾讯与东方财富至少匹配10只候选股，95分位价格差不超过0.3%；
- 校验失败时仍发布失败原因，但下游任务不得给出股票推荐。

## 免费数据边界

公共行情端点没有商业SLA，可能限频、断连或调整字段。本项目通过低频调用、重试、双源校验和硬性空缺机制降低风险，但不会把免费接口包装成专业授权行情。
